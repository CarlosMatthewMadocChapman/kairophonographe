# Examples

Examples are reproducible fixtures, not templates.

Each directory contains:

- `session.json` — normalized input and provenance;
- `expected_output.json` — deterministic output from the 0.6.0 reference engine;
- `README.md` — scope and caveats.

`new-terrain/` is the active anti-recycling regression example. The other examples are retained only for explicit reference and comparison.
