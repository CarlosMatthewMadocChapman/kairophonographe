# La Rousselie — reference session

This fixture encodes a hot, humid evening storm as a **reference example**. Weather values are treated as user-provided/reconstructed for the example, not as an independently verified meteorological record.

Its purpose is regression testing: high heat, high humidity, active wind, precipitation and strong dynamic variability should produce an active-weather regime, elevated density, moving space and warm low-frequency body.

The example does not govern future scenes.
