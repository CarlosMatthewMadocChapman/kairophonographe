# Changelog

## 0.6.0 — 2026-10-04

First consolidated public research release.

### Added

- explicit weather, time, season, geology, sound, place, kinetic and vocality mappings;
- deterministic reference translator and read-only mapping API;
- offline-validatable JSON Schemas;
- strict provenance fields for measured, API-derived, observed, estimated and simulated inputs;
- anti-recycling gate and novelty dimensions;
- sensor compatibility and Raspberry Pi acquisition architecture;
- reproducible example sessions separated from governing rules;
- listening evaluation protocol with source-retention, singularity and musical-value criteria;
- public promotion record for moving tested research into the stable layer;
- citation, licensing, publication and Radio du Futur integration documentation.

### Design decision

The repository exposes mappings as inspectable artistic rules. It deliberately avoids opaque geographic-to-style assignment and treats examples as non-governing evidence.
